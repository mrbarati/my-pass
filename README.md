# 🔐 رمز من (My Pass)

**مدیریت رمز عبور و بوکمارک** — یک برنامه دسکتاپ سبک، سریع، آفلاین و قابل حمل برای ویندوز.

> ساخته شده با Electron + React 19 + Tailwind CSS v4 + SQLite

## ✨ ویژگی‌ها

- 🔒 **رمزنگاری AES-256-GCM** با کلید مشتق‌شده از رمز اصلی (scrypt)؛ کاملاً آفلاین
- 💳 **انواع آیتم**: ورود به سایت، کارت بانکی، یادداشت امن، Wi-Fi (با QR اتصال) + فیلدهای سفارشی
- ⏱️ **کد ورود دومرحله‌ای (TOTP)** داخل برنامه
- 🩺 **سلامت رمزها**: شناسایی رمزهای ضعیف، تکراری و قدیمی + نوار قدرت رمز
- 🎲 **تولید رمز تصادفی و عبارت عبور** (Passphrase)
- 🧹 **پاک شدن خودکار کلیپ‌بورد** پس از کپی رمز (قابل تنظیم)
- 🔐 **قفل خودکار**: پس از مدت بی‌فعالیتی، هنگام قفل شدن ویندوز یا کوچک کردن پنجره
- 🗑️ **سطل زباله** با امکان بازگردانی (حذف دائمی پس از ۳۰ روز)
- ⭐ **علاقه‌مندی‌ها**، مرتب‌سازی (نام، تاریخ، پراستفاده‌ترین) و فیلتر بر اساس نوع
- ☑️ **عملیات گروهی**: انتقال، برچسب‌گذاری، علاقه‌مندی و حذف چند مورد با هم
- 📁 **گروه‌بندی و برچسب‌گذاری** رنگی با کشیدن و رها کردن
- 📥 **ایمپورت CSV** از Chrome/Edge، Firefox، Bitwarden و KeePass + ایمپورت/اکسپورت JSON (رمزنگاری‌شده)
- 🕒 **بک‌آپ خودکار دوره‌ای** در پوشه دلخواه + بک‌آپ دستی
- 🎨 **رابط کاربری مدرن** با حالت تیره/روشن و ۱۰ رنگ اصلی، تاریخ‌های شمسی
- 🌐 نمایش اختیاری آیکون سایت‌ها (پیش‌فرض خاموش)
- 🚀 **نسخه نصبی و قابل حمل (Portable)**

## 🚀 نصب و اجرای توسعه

```bash
npm install
```

در پایان نصب، `postinstall` ماژول `better-sqlite3` را برای نسخه Electron پروژه آماده می‌کند.

**اجرا با Hot Reload** (دو ترمینال):

```bash
npm run dev
```

```bash
npx electron .
```

**اجرای سریع بدون سرور Vite:**

```bash
npm run electron:dev
```

این دستور ابتدا `vite build` را اجرا می‌کند و Electron نسخه build شده را باز می‌کند (اگر سرور Vite در حال اجرا نباشد، Electron خودکار از `dist/` استفاده می‌کند).

## 📦 بیلد و انتشار

۱. نسخه را در `package.json` (فیلد `version`) و `CHANGELOG.md` به‌روز کنید.

۲. خروجی بگیرید:

```bash
npm run electron:pack
```

خروجی در پوشه `dist-electron/`:

| فایل | توضیح |
|------|-------|
| `MyPass-Setup-<version>.exe` | نصب‌کننده (NSIS) |
| `MyPass-Portable-<version>.exe` | نسخه قابل حمل؛ دیتابیس کنار فایل exe ساخته می‌شود |

> فایل‌ها امضای دیجیتال (Code Signing) ندارند؛ ممکن است Windows SmartScreen هنگام اجرای اول هشدار بدهد.

## 💾 محل ذخیره دیتابیس

| حالت | مسیر |
|------|------|
| توسعه | `./data/data.mypass` |
| نسخه نصبی | `%APPDATA%\My Pass\data.mypass` |
| نسخه Portable | کنار فایل `MyPass-Portable-*.exe` |
| باز کردن مستقیم | دوبار کلیک روی هر فایل `.mypass` |

مسیر دقیق در «تنظیمات ← درباره نرم‌افزار» نمایش داده می‌شود. برای انتقال به سیستم دیگر کافی است فایل `data.mypass` را کپی کنید.

## 🔐 نکات امنیتی

- رمزها، کلیدهای TOTP، فیلدهای سفارشی و تاریخچه رمزها با **AES-256-GCM** رمزنگاری می‌شوند.
- کلید رمزنگاری با **scrypt** از رمز اصلی و یک salt تصادفی ساخته می‌شود، فقط در حافظه پروسه اصلی نگه داشته می‌شود و هنگام قفل پاک می‌شود.
- هش رمز اصلی هرگز به رابط کاربری ارسال نمی‌شود.
- رابط کاربری با `contextIsolation` و Content-Security-Policy سخت‌گیرانه اجرا می‌شود و لینک‌ها فقط در مرورگر سیستم باز می‌شوند.
- برنامه به اینترنت وصل نمی‌شود؛ تنها استثنا نمایش آیکون سایت‌هاست که به‌صورت پیش‌فرض خاموش است.
- **رمز اصلی قابل بازیابی نیست.** در صورت فراموشی، اطلاعات قابل بازگشت نیستند.
- فایل‌های CSV ایمپورت‌شده رمزنگاری ندارند؛ پس از ایمپورت آن‌ها را حذف کنید.

## 🐛 عیب‌یابی

**خطای `better-sqlite3` یا «Cannot find module»:**

```bash
npm run postinstall
```

**پنجره سفید در حالت توسعه:** ابتدا `npm run build` را اجرا کنید یا سرور `npm run dev` را بالا بیاورید.

**هشدارهای npm هنگام نصب:** برخی هشدارها از وابستگی‌های داخلی electron-builder است و تا زمانی که آسیب‌پذیری گزارش نشود مشکلی نیست.
